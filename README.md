# PTPM-VKI
### Практическое задание: Срез знаний по юнит тестам.

#### 🔧 1. Описание класса и метода
Необходимо реализовать класс `Converter` с одним статическим методом со следующей сигнатурой:
```python
@staticmethod
def do(x: float) -> int:
```

#### 🏆 2. Алгоритм работы метода 
Метод принимает на вход вещественное число типа `float` (всегда с точностью 1 знак после запятой, например: `-94.5`, `65.7` и т.д.) и возвращает целое число (`int`) по следующему алгоритму:

* **x ∈ [100.7; + ∞)** -> метод возвращает число `1000`.
* **x ∈ (0; 100.7)** -> метод возвращает целую часть числа x путем отбрасывания дробной части (эквивалентно `int(x)`).
* **x == 0.0** -> генерируется исключение `ValueError` (аналог ArgumentException).
* **x ∈ [-30.4; 0)** -> метод возвращает целую часть числа x путем отбрасывания дробной части (эквивалентно `int(x)`) минус `5`.
* **x ∈ (-∞ ; -30.5]** -> метод возвращает число `-2000`.

#### 🔍 3. Требования к тестированию 
Напишите **юнит-тесты** с использованием стандартного модуля **`unittest`**. Тесты должны полностью покрывать и проверять весь заявленный функционал, включая:
* Положительные и отрицательные сценарии;
* Граничные значения диапазонов;
* Проверку генерации исключения при `x == 0`.
